# 企业内网级 AI 知识库与 ERP 报表问答解决方案（售前 PoC 版）

## 1. 客户常见业务痛点

1. **知识分散难检索**：制度 SOP、设备手册、财务/采购规范散落在企业共享盘、邮件与本地网盘，新员工培训慢、老员工找文件耗时。
2. **权限隔离是红线**：财务报价、采购底价、人事制度绝对不能被普通员工搜到；通用云端问答工具缺乏与企业 AD 域控/部门分组对齐的权限控制。
3. **业务查数高频打断 IT**：财务、运营、采购频繁找 IT 拉取 ERP 临时报表，IT 陷入重复 SQL/报表维护。
4. **数据不出内网诉求**：传统制造、贸易、医药类企业对核心文档和 ERP 数据高度敏感，要求支持私有化部署或严格的数据脱敏网关。

---

## 2. 推荐部署拓扑

- **轻量 PoC 阶段（1~2 周）**：单台内网应用服务器（Docker Compose 运行 FastAPI + pgvector），大模型调用企业合规云端 API（仅传输脱敏后的授权片段）。
- **生产私有化阶段（4~6 周）**：内网独立部署应用集群 + pgvector + 本地开源大模型推理服务（vLLM / Ollama，如 Qwen 系列），通过防火墙策略严格限制外网访问，身份认证对接企业现有 AD 域控 / LDAP。

---

## 3. 核心安全与治理设计

1. **检索前权限过滤（Pre-retrieval RBAC）**：查询向量库或知识库前，先根据用户所属 AD 组/部门标签过滤文档集合，确保无权文档**永不进入**大模型上下文。
2. **ERP 只读白名单机制**：报表问答仅开放只读数据库账号，禁止任意 DDL/DML，优先通过预注册参数化查询模板或受控视图暴露数据。
3. **防提示词注入（Prompt Injection）**：拦截要求忽略系统规则、越权读取全库或输出系统提示词的恶意输入。
4. **全链路审计留痕**：记录每次查询的操作人角色、时间、问题摘要、命中的文档 ID 与是否触发拒答，满足内控审计要求。

## 4. 4 周 PoC 交付里程碑（参考）

| 阶段 | 周期 | 核心交付物 | 验收标准 |
|---|---|---|---|
| W1 调研与盘点 | 第 1 周 | 梳理 2~3 个试点部门文档目录、权限矩阵与 10 个高频问答场景 | 客户确认权限边界与 30 道标准验收题 |
| W2 环境与摄取 | 第 2 周 | 完成内网 Docker 部署、脱敏文档切分入库、RBAC 角色打通 | 离线单测与权限隔离冒烟测试 100% 通过 |
| W3 调优与评测 | 第 3 周 | 混合检索/Rerank 调优、引用格式优化、30 题固定集实测 | 输出《PoC 评测报告》（准确率、拒答率、耗时、成本） |
| W4 演示与验收 | 第 4 周 | 面向客户业务与 IT 负责人现场演示、输出生产扩容报价与二期计划 | 完成 PoC 验收签字并转入正式实施 |
